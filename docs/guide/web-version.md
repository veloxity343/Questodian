# The web version (iPad and other tablets)

[Documentation](../README.md) › The web version

Questodian also runs entirely inside a web browser, with nothing to install and no server: open
https://veloxity343.github.io/Questodian/. After the first visit it works offline. It's the same
app as the desktop version, made for an iPad, but it runs in any recent browser.

## Adding it to the Home Screen

On an iPad, open the address in Safari, tap **Share**, then **Add to Home Screen**. Questodian then
opens from its icon like an app, full screen. Use it from the Home Screen rather than a Safari
tab:
- **Safari tabs** may lose a site's data after seven days of using Safari without visiting it.
  Home Screen web apps are exempt from that rule.
- **The Home Screen app keeps its own data,** separate from Safari's. Campaigns made in a Safari
  tab don't appear in the Home Screen app, and the other way round.

## Where your data is

Everything is stored in the browser, on that device only. Nothing is uploaded anywhere. Removing
the app from the Home Screen or clearing the site's data can delete it, so save a full backup now
and then:
- On the **Data** page, **⬇ Full backup (all data)**. On an iPad this opens the Share sheet:
  choose **Save to Files** and pick iCloud Drive or a folder. Other exports open the Share sheet
  too.
- If the Share sheet doesn't open straight away (preparing a large backup takes a moment), a
  **Save …** button appears below: tap it.
- A week after the last full backup from that browser, the **Data** link in the top bar shows a
  small dot as a reminder.

## Moving data between devices

The web version and the desktop app keep separate data. To move a campaign between them, export it
on one and import it on the other (see [Data and backups](data-and-backups.md)). Use **Overwrite**
to restore a backup. Each import is a copy: changes made afterwards stay on the device where you
made them.

An export from a newer version of Questodian can't be imported into an older one, so update the
desktop app first if it's behind.

## Showing things to players

On a tablet, **📽 Show to players** switches the same window to the players' view; **← DM screen**
(top left) brings you back, with your tabs as you left them. To put it on a TV, use screen
mirroring (AirPlay on an iPad). In a browser on a computer, it opens a second window as the
desktop app does.

## Several windows

You can open Questodian in more than one tab or window. One of them holds the data and the others
borrow it. If the one holding it goes into the background while another window is in view, it
hands the data over. If it closes, another takes over. A change being saved at that moment is sent
again to the new one, and is made only once.

## Updates

New versions download in the background while you're online. One is used once every Questodian
window has been closed, so an open app never changes under you.

## Checking a browser

The **Data** page has a **This browser** panel. **Check this browser** tries everything the web
version relies on and lists the results. It adds a test handout and deletes it again. If something
fails, **Copy report** copies the list so you can send it with a bug report.
